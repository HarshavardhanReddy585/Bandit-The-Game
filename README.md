# OverTheWire Bandit write-ups

My step-by-step notes for the [OverTheWire Bandit](https://overthewire.org/wargames/bandit/) wargame, which teaches Linux and shell basics over SSH.

| Write-up | Levels |
|---|---|
| [Week 1](Week_1.md) | Levels 0 to 11 |
| [Week 2](Week_2_Write_up.md) | Levels 11 to 13 |

Topics covered: SSH (including key-based login), finding and reading files (`find`, `grep`, `sort`, `uniq`, `strings`), encodings (base64, ROT13, hexdumps) and file permissions.

> Spoiler warning: these notes walk through the solutions.
